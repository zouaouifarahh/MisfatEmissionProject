{{ t('sec6.fiches') }}

{{ t('p.s6.l1.titre') }}

{{ t('p.s6.posteVise') }} : {{ t('p.s6.l1.poste') }}

{{ t('p.s6.actions2028') }} : audit énergétique réglementaire des trois sites ; comptage divisionnaire par atelier, sans lequel aucune économie n'est attribuable ; variation de vitesse sur les moteurs de ventilation et de pompage ; chasse aux fuites d'air comprimé ; relamping LED des halls de production.

{{ t('p.s6.actions2030') }} : récupération de chaleur sur les compresseurs et les groupes froids ; pilotage centralisé des utilités ; renouvellement des équipements les moins performants au fil des amortissements.

{{ t('p.s6.impactAttendu') }} : −10 à −20 % du Scope 2. {{ t('p.s6.investissement') }} : modéré, retour généralement inférieur à trois ans sur la part comptage et air comprimé.

{{ t('p.s6.l1.note') }}

{{ t('p.s6.l2.titre') }}

{{ t('p.s6.posteVise') }} : {{ t('p.s6.l2.poste') }}

{{ t('p.s6.actions2028') }} : étude de portance des toitures et dimensionnement photovoltaïque en autoconsommation ; première tranche sur le site à la plus forte consommation diurne, l'autoconsommation valant d'autant plus que la production coïncide avec la charge.

{{ t('p.s6.actions2030') }} : extension aux autres sites ; contractualisation d'un approvisionnement renouvelable (contrat d'achat direct ou garanties d'origine), qui ouvre la publication market-based exigée par le GHG Protocol dès lors que de tels instruments existent.

{{ t('p.s6.impactAttendu') }} : −15 à −30 % du Scope 2 par l'autoproduction, jusqu'à −70 % du Scope 2 market-based par la contractualisation.

{{ t('p.s6.l2.note') }}

{{ t('p.s6.l3.titre') }}

{{ t('p.s6.posteVise') }} : {{ t('p.s6.l3.poste') }}

{{ t('p.s6.actions2028') }} : cartographie carbone du panel fournisseurs ; substitution des facteurs monétaires par des facteurs physiques, puis par des données primaires ; introduction d'un critère carbone dans les appels d'offres ; recours à l'acier et aux plastiques recyclés là où les spécifications de filtration l'autorisent.

{{ t('p.s6.actions2030') }} : engagement des fournisseurs représentant 80 % des achats sur une trajectoire propre ; éco-conception des références à plus fort volume, seul levier qui agisse simultanément sur les achats et sur la fin de vie.

{{ t('p.s6.impactAttendu') }} : −10 à −25 % de la catégorie 1, avec un effet d'entraînement sur les catégories aval.

{{ t('p.s6.l3.note') }}

{{ t('p.s6.l4.titre') }}

{{ t('p.s6.posteVise') }} : {{ t('p.s6.l4.poste') }}

{{ t('p.s6.actions2028') }} : mesure des tonnes·kilomètres par mode, préalable à toute optimisation ; amélioration du taux de remplissage ; massification des expéditions ; réduction du fret aérien, dont le facteur dépasse d'un ordre de grandeur celui du maritime.

{{ t('p.s6.actions2030') }} : report modal du routier vers le ferroviaire et le maritime sur les flux longs ; sourcing régional sur les familles où le coût logistique carbone dépasse l'écart de prix ; exigence progressive de carburants alternatifs auprès des transporteurs.

{{ t('p.s6.impactAttendu') }} : −15 à −25 % des catégories de transport.
